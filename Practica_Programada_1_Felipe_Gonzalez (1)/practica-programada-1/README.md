# Práctica Programada 1 — HTML y CSS

Abra `primera-parte/index.html` y `segunda-parte/index.html` en su navegador. Cada página usa su propio `styles.css`. No necesita instalar nada.

## Primera parte
Formulario basado en el ejercicio indicado de freeCodeCamp: https://www.freecodecamp.org/learn/2022/responsive-web-design/learn-html-forms-by-building-a-registration-form/step-1

Incluye campos personales, contraseña, tipo de cuenta, foto, edad, referencia, biografía y aceptación de términos. Conserva el destino de demostración del tutorial; use datos ficticios. Estos archivos no acreditan haber completado los pasos en su cuenta de freeCodeCamp; complete también el tutorial si el profesor solicita ese avance.

## Segunda parte
Perfil médico ficticio con cuatro enlaces de navegación, nombre y especialidad con clases, descripción con id, botón para ir a contacto y tres comentarios con fechas. Usa Flexbox horizontal en escritorio y vertical en móvil, modelo de caja, selectores de descendientes, hijos y atributos, y efectos hover. El botón de contacto abre el correo y no reserva una cita real.

## Cómo entregar
1. Cree en GitHub el repositorio `sc502-3c2024-felipegonzalez-trabajosindividuales`. El año 2024 se conserva porque aparece en la nomenclatura del documento; cámbielo solo si el profesor indica otra cosa.
2. Abra una terminal y clone su repositorio, sustituyendo TU-USUARIO:

```bash
git clone https://github.com/TU-USUARIO/sc502-3c2024-felipegonzalez-trabajosindividuales.git
cd sc502-3c2024-felipegonzalez-trabajosindividuales
```

3. Descomprima el ZIP y copie la carpeta `practica-programada-1` dentro del repositorio clonado.
4. Ejecute:

```bash
git add practica-programada-1
git commit -m "Completar practica programada 1 de HTML y CSS"
git push
```

5. Entregue el ZIP y el enlace del repositorio en la plataforma de la Universidad. Confirme que el profesor pueda acceder al repositorio.

La carpeta `segunda-parte` usa guion para evitar espacios y corresponde a la carpeta “segunda parte” de las instrucciones.
